# Super Mario 64 VR

Online co-op Mario 64 in VR, built on sm64coopdx.

Install it through the [Multiverse VR Hub](https://github.com/RaYRoD-TV/MVRH). One exe.. it pulls the official sm64coopdx release, applies my VR patch & keeps it updated. There's a standalone Quest build in there too.

Nothing to download here anymore, no PC builds & no Quest builds. The hub is the one place it all lives now, source included.
